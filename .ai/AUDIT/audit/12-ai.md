The platform uses **OpenAI GPT-4o-mini exclusively** for all AI-generated content. There is no multi-provider routing, no fallback model, and no abstraction beyond a thin wrapper class.

## Intelligence Engine AI Design

### Approach: Calculate-then-Narrate

**The best design decision in the codebase.** The intelligence route does not ask the AI to perform financial calculations. Instead, it:

1. Runs a deterministic TypeScript cashflow engine (`calculateCashflow`, `calculateCampaignROI`, etc.)
2. Injects the calculated numbers as facts into the prompt
3. Instructs the model: *"do NOT recalculate numbers"*

**Benefits:**
- Financial numbers are always accurate (100% deterministic)
- AI only writes the narrative — where hallucination risk is acceptable
- Confidence scores are set deterministically by the application logic, not the AI

**Evidence:** `app/api/intelligence/route.ts:462–465`:
```
You are Egypt's top real estate financial analyst.
The cashflow has already been CALCULATED. Your job is to INTERPRET and EXPLAIN — do NOT recalculate numbers.
```

## Prompt Quality Analysis

### Feasibility Prompt (`buildFeasibilityPrompt`)
**Length:** ~600 lines of prompt string (template literal)  
**Structure:** Pre-calculated financials in a table → explicit verdict → instruction for JSON output format  
**JSON enforcement:** `Return ONLY valid JSON (no markdown, start with {)`  
**Confidence:** Deterministic (65–85% based on what market data user provides)

**Assessment:** Thorough. The prompt enforces specific Arabic text for verdict values (`مجدي`, `مجدي مشروط`, `غير مجدي`) to enable deterministic UI rendering. Strong evidence-based design.

### Talent Finder

**File:** `app/api/research/talent/route.ts:31–60`

## AI Risk Assessment

| Risk | Severity | Mitigation |
|---|---|---|
| Financial data hallucination | LOW | Pre-calculated numbers, AI writes narrative only |
| Talent salary data staleness | MEDIUM | Disclaimer shown, but no real data source |
| JSON parse failure from malformed AI response | MEDIUM | Try/catch with 500 + raw fragment in error |
| No model fallback | MEDIUM | If OpenAI degrades, all AI features fail |
| `temperature: 0.3` on financial reports | LOW | Appropriate (low randomness for structured output) |
| `temperature: 0.4` on talent report | LOW | Slightly higher randomness acceptable for narrative |
| `max_tokens: 4000` on feasibility (longest prompt) | LOW | May truncate very large responses — no detected truncation handling |

**SerpAPI:** 100 calls/month free; $50/month for 5,000 calls. Lead Finder uses 1 call per search. At STARTER plan (20 reports/month), SerpAPI cost is within free tier per user. At AGENCY (300/month), SerpAPI becomes a meaningful cost.

## AI Infrastructure Gaps

| Gap | Impact |
|---|---|
| No model versioning/pinning | Breaking changes in GPT-4o-mini behavior would silently affect all reports |
| No AI usage tracking | Impossible to compute cost per user or per report type |
| No JSON schema validation on AI output | Invalid AI responses cause 500 errors |
| No retry logic on AI failures | Transient OpenAI errors fail the entire request |
| Cloudflare Worker fallback (`CLOUDFLARE_WORKER_URL`) not verified | Env var exists in examples but the failover logic is not visible in source |
